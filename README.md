# materials · 项目素材仓

本仓按项目分文件夹，存放各项目可公开的素材（语料、转录、加工件）。
与其它仓库的分工：代码在 pys，面板在 apphub，网页在 htmls，私有数据在 data（私有仓）。素材既不是代码、也不是运行数据，单独成仓。

## 准入规则（写死）

- 只收**可公开**的素材；拿不准是否可公开的，先不要进本仓。
- **永不入仓**：敏感语料（例如 nameclean 的文件名词料）、健康记录、个人数据、凭据类文件（credentials / token / cookie / 密钥 / 账号文件），以及任何含真实密钥、口令、个人身份信息的文件。
- 每个项目一个文件夹，文件夹内放一份 README，说明素材的来源与构成。

## 项目索引

- `beastlib/` — 野兽素材库（MrBeast 素材库）的语料：Bilibili 策展批与 YouTube 加工批的总结与转录。
