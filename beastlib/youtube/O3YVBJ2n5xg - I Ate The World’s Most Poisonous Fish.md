# 我吃了世界上最毒的鱼

## 视频简介

视频记录了几个人试吃河豚的过程。河豚被称作世界上最毒的鱼，处理时只要有一处失误就可能致命；这份河豚出自专业厨师之手，但参与者对是否真的下口仍然十分犹豫。

## 内容摘要

视频开头说明河豚是世界上最毒的鱼，处理过程中的一个小失误就可能致死。有人强调这份河豚由专业厨师制作，按理说不会带毒，但也有人指出"应该没毒"并不等于保证，如果厨师处理错了，大家只能一起承担后果。参与者对着鱼肉反复犹豫，说不确定要不要吃，有人觉得嘴里刺痛，还有人感到舌头沉重，随即怀疑是不是中毒。最后有人判断不值得为这一口冒生命危险，决定不把鱼肉吞下去，旁边的人则指出他确实没有吞。

## 关键事件

### E01｜介绍河豚的毒性
视频开篇说明这是河豚，世界上最毒的鱼，处理时只要出一个小失误就可能致命。
- 原文依据："This is puffer fish, the most poisonous fish in the world."

### E02｜强调由专业厨师处理
有人说明这份河豚是专业厨师做的，所以理论上不应该有毒。
- 原文依据："This was made by a professional, so it shouldn't be poisonous."

### E03｜对"应该无毒"提出质疑
有人抓住"应该"这个说法反问：万一厨师处理错了，大家就只能一起完蛋。
- 原文依据："If the chef prepared it wrong, at least we all go down together, right?"

### E04｜参与者犹豫是否下口
面对鱼肉，几个人都表示不确定自己是否真的想吃。
- 原文依据："I'm not sure if I want to eat this. I'm not sure either."

### E05｜出现刺痛感
有人描述口腔有轻微的刺痛感，气氛开始变得不安。
- 原文依据："I feel like a little prickly."

### E06｜感觉舌头沉重
随后有人表示舌头变得很沉，进一步怀疑是不是出现了中毒迹象。
- 原文依据："Why is my tongue so heavy?"

### E07｜判断不值得冒险
有人直言不想为这件事丢掉性命，决定不把嘴里的鱼肉吞下去。
- 原文依据："I don't think this is worth dying over. I don't think I'm gonna swallow it."

### E08｜确认并未吞下
旁人对他说其实并没有吞下去，以一句反问结束了这段尝试。
- 原文依据："You didn't swallow it. That you kidding me?"
