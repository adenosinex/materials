# 我的第一个KEM打击！

## 视频简介
这是一期《使命召唤：幽灵》的单人实况解说，作者展示自己首次打出25连杀的KEM打击，并借这段录像讲解听声辨位在枪战中的作用。全片由旁白配合对局画面推进，节奏随性。

## 内容摘要
作者当天上午连续玩了约五小时才拿到这个连杀，而且是在自己最不喜欢的地图上完成的。他解释KEM打击只能用枪械连续击杀25人，必须在一条命内打完，其他连杀奖励不计入。核心建议是重新戴上耳机听脚步声：本作脚步声接近《现代战争2》那样清晰，即使对手使用静步也能听到，可以提前抢占先手、避免被绕后。他以蜜獾开局，中途换枪，并剪掉了偏蹲守的片段。临近达成时他差两杀，打法转为保守，心跳得厉害，最终仍完成连杀，并想把KEM打击做成系列。

## 关键事件

### E01｜说明KEM打击是什么
作者先解释KEM打击的定义：用枪械打出25连杀，性质相当于《现代战争3》的MOAB。
- 原文依据："a Kim Strike is a twenty five kill streak with your gun"

### E02｜连玩五小时后终于达成
他当天上午打了大约五小时，才第一次拿到这个连杀，情绪非常激动。
- 原文依据："I played for like five hours this morning and I finally got it"

### E03｜在最讨厌的地图上完成
这次连杀发生在他平时最不喜欢的地图上，他原本看到这张图就想退出。
- 原文依据："I managed to get it on this map, which is my least favorite map"

### E04｜把听声辨位列为核心技巧
他给出第一条建议：想拿KEM打击就必须听脚步声，这是当天才改变的习惯。
- 原文依据："if you want to get a Kim strike, you need to sound tour"

### E05｜本作脚步声足够清晰
他指出《幽灵》的脚步声很大，接近《现代战争2》，不用高端耳机也能听到隔壁房间的对手。
- 原文依据："footsteps are so loud. It's like Modern Warfare Two."

### E06｜带增幅技能可破静步
即使对手装了静步，只要自己带增幅，仍然能听见对方，从而防止被偷袭。
- 原文依据："even if they're using dead silence, you can still hear them"

### E07｜开局用蜜獾，中途换枪
本局他先用蜜獾，随后捡起了地上另一把枪继续打。
- 原文依据："I was using the honey badger in this game to start off with"

### E08｜剪掉蹲守片段
他承认原录像中有一段打法偏蹲守，已在剪辑时删去。
- 原文依据："I cut out a little part of this gameplay because it was a little bit campy"

### E09｜评价本作接近现代战争2
他表示自己很喜欢《幽灵》，认为水准与《现代战争2》接近，但也承认有新鲜感成分。
- 原文依据："It's definitely up there with Modern Warfare two"

### E10｜差两杀时转为保守
临近达成时他只差两个人头，紧张到心跳加速，只能打得很保守。
- 原文依据："I'm like two kills off, and so I'm playing really defensive"

### E11｜打算做成固定系列
他说想把每次拿到KEM打击都上传，做成频道里的一个系列。
- 原文依据："I was thinking about making this a series on my channel"
