# 我讨厌的事 第一期

## 视频简介

这是「我讨厌的事」系列吐槽节目的第一期。主播以口播方式抱怨电台总是重复播放同一批热门歌曲、自己又懒得刻录 CD，随后谈到 YouTube 上的刷屏与互赞，中途插入一段反讽式的赞助商口播，最后因喜欢的电视节目即将开播而草草收尾。

## 内容摘要

视频开场，主播宣布这是「我讨厌的事」第一期，第一个抱怨对象是电台：他每天都能听到 Taylor Swift 的《Wildest Dreams》，认为电台常年不换歌单，运营者也不愿更新曲目。他表示自己懒得刻录 CD 替代电台，随后用反讽语气念完赞助商 Razor 鼠标的口播。第二个抱怨对象是 YouTube 上的刷屏与互赞、互订，他承认自己十三岁时也做过类似的事，但强调刷屏无法让人出名，只会招来反感，建议把时间用来做内容。结尾他提到曾拍过朋友砸坏自己笔记本的视频，原本还想吐槽高中所学无用，却因喜欢的节目即将开播而中断。

## 关键事件

### E01｜宣布首期节目并抛出第一个抱怨对象

主播以「我讨厌的事」第一期开场，表示第一项抱怨是电台每天播放同样的音乐。

- 原文依据："My first complaint is radio stations because they play the same music every day"

### E02｜抱怨电台反复播放同一首热门歌曲

主播称当时电台里隔一首就放 Taylor Swift 的《Wildest Dreams》，并抱怨自己一天要听三遍。

- 原文依据："every other song on the radio is Wildest Dreams by Taylor Swift"

### E03｜考虑自制 CD 但因懒惰放弃

主播一度想自己刻 CD 来替代电台，随后说明自己懒，不想维护和定期更新歌单。

- 原文依据："Is because I'm lazy I don't want to keep up with the CD"

### E04｜批评电台运营者不更换歌单

主播称电台播新歌的思路本身没问题，问题在于 2015 年的运营者整年播放同样的歌且不做调整。

- 原文依据："the problem with radio stations in 2015 is freaking idiots run them"

### E05｜反讽式念赞助商口播

主播介绍赞助商 Razor，用夸张的反讽描述称花七十美元买的鼠标插上后电脑无法开机，还会让人误以为中毒。

- 原文依据："for seventy dollars you can buy a mouse that when you plug it in your computer won't start up"

### E06｜转向第二个抱怨：刷屏

结束赞助口播后，主播把话题转到 spam（刷屏、刷评论），表示自己无法理解这种行为。

- 原文依据："the next thing I'm gonna complain about is spam"

### E07｜说明刷屏无法带来名气

主播认为没有人是靠刷屏出名的，看到这类评论的人只会点踩，因此刷屏对频道没有帮助。

- 原文依据："it's impossible to become famous through spam"

### E08｜承认自己十三岁时也刷过屏

主播不把自己当作完人，承认刚建频道、十三岁时也做过少量类似行为。

- 原文依据："I've never done spam because I have done my fair share of spam back when I was thirteen"

### E09｜建议把刷屏时间用于做内容

主播表示无论是刷屏、互订还是互赞都无助于频道成长，不如把时间用来制作内容。

- 原文依据："take that time you spend doing spam, put it towards making content"

### E10｜回应笔记本的去向

主播主动解释自己的笔记本电脑为何不见了，称曾拍过朋友把电脑砸坏的视频。

- 原文依据："I made a video of my friend smashing my laptop"

### E11｜原计划吐槽高中，因节目开播而收尾

主播说原本还想抱怨高中所教内容的无用，但提到自己喜欢的节目即将播出，视频随即结束。

- 原文依据："I was going to complain a little bit about high school"
