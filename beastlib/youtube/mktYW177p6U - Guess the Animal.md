# 猜猜是什么动物

## 视频简介
参与者蒙着眼睛把手伸进看不见的动物围栏，只能靠触感和声音判断里面是什么。视频依次出现猴子、水豚、短吻鳄、鸸鹋等动物，最后一只让在场者立刻要求把它拿走。

## 内容摘要
视频开始时，出镜者反复说自己很害怕，但仍决定伸手尝试，并请朋友多加小心。最初摸到的是猴子；随后有人先猜老鼠、又猜是耳朵，实际是水豚，还被水豚舔了手。接下来猜鬣狗时被告知"很接近"。中途出现"猜对就要订阅"的说法。之后他摸到黏滑、有鳞片的东西，认出是短吻鳄，有人对 Chandler 说祝你好运并让其继续。再往后，他判断体型太大不像鸡，猜鸵鸟，答案是鸸鹋；最后一次他直接认出是熊，并要求把它拿走。

## 关键事件
### E01｜带着恐惧开始尝试
出镜者多次表示自己非常害怕，仍让同伴开始，并请求对方小心一些。
- 原文依据："I'm terrified. I'm terrified. All right, go for it."

### E02｜第一只被认成猴子
伸手后出现声响，他先问那是什么，随后确认是猴子，并判断里面应该是危险的东西。
- 原文依据："Is that a monkey? Yeah, that's a monkey."

### E03｜从老鼠改判为水豚
他先问摸到的是不是耳朵、是不是老鼠，最终说出答案水豚。
- 原文依据："Is that an ear? Is it a rat? It's a capybara."

### E04｜水豚舔了手
他察觉动物有动作，随后发现对方舔了自己的手。
- 原文依据："Wait, what's it doing? Oh, it gave you a licky."

### E05｜猜鬣狗被判接近
他提出鬣狗这个答案，旁人回应说已经很接近。
- 原文依据："Is it a hyena? You were close."

### E06｜提出猜对就订阅的条件
在继续之前，他提出一个条件：如果这次猜对，对方就要订阅频道。
- 原文依据："if I guess this right, you have to subscribe"

### E07｜摸到黏滑有鳞的短吻鳄
他先表示不想看，随后描述触感黏滑、有鳞片，并认出是短吻鳄。
- 原文依据："Oh, wait, it's slimy. Yeah. It's scaly. Oh, an alligator."

### E08｜对 Chandler 说祝好运
有人提到对方让自己把手伸了进去，并对名为 Chandler 的人说祝你好运，让其继续。
- 原文依据："Whoa, you let me put my hand in there. Good luck, Chandler."

### E09｜排除鸡后猜中鸸鹋
他先判断体型太大不可能是鸡，接着猜鸵鸟，得到的答案是鸸鹋。
- 原文依据："Too big to be a chicken. Is this an ostrich? It's an emu."

### E10｜认出熊并要求拿走
他明确说自己知道是什么，连续确认是熊，随后要求把这只动物从身边带走。
- 原文依据："This is a bear. Wait, this is a bear. Get it away from me."
