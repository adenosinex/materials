# 约500美元的视频剪辑用电脑

## 视频简介
作者坦言自己对电脑硬件几乎一无所知，却要推荐一台约500美元的整机。他的判断标准很实际：能否同时流畅运行剪辑、特效与图像软件，以及录制游戏时的表现如何。

## 内容摘要
视频围绕一台约500美元的整机展开。作者说自己只会用不会拆，评价完全来自日常使用体验：剪辑、特效与图像软件可以同时运行，鼠标键盘随机器附赠，机器已使用一年多。游戏方面，不录制时没有卡顿，用 Fraps 录制会出现掉帧，改用 OBS 或把画面缩到720p窗口可以缓解。他明确表示不适合在电脑上录制第一人称射击，并提醒链接在简介中、自己没有收取佣金。

## 关键事件

### E01｜开场先声明自己不懂电脑
作者表示知道观众想看便宜的剪辑用电脑，但在推荐之前必须先说清楚：他对电脑硬件并没有专业知识，评价只基于自己实际使用的那一台。

- 原文依据："But I must start off this video by saying I know nothing about PCs"

### E02｜核心卖点：三款软件可同时运行
他强调身边这台机器在视频制作上表现突出，可以同时跑剪辑、特效和修图三类软件而不卡顿，因此不只是能做普通的口播类内容。

- 原文依据："it can run Sony Vegas, it can run After Effects, and it can run Photoshop"

### E03｜价格与配件
这台机器价格在500美元档位，并且附带键盘和鼠标，作者说自己至今仍在使用附赠的鼠标，认为键盘对得起价格，不必额外购买上百美元的键盘和八十美元的鼠标。

- 原文依据："This PC is five hundred dollars. And may I say it includes this mouse"

### E04｜面向笔记本剪辑的创作者
他对用笔记本做视频或刚想做频道的人说，不需要为了渲染视频去花1000美元买新台式机，这台500美元的机器已经够用，链接放在简介中且他没有拿佣金。

- 原文依据："you don't need to drop a thousand dollars on a new desktop PC"

### E05｜游戏表现：不录制时流畅
作者以自己常玩的射击游戏为例，说明在不录制的情况下没有任何卡顿；一旦用对硬件要求很高的 Fraps 录制，就会出现少量帧率下降，但仍勉强可玩。

- 原文依据："as long as that was not recording, there was no lag"

### E06｜适用与不适用的场景
他建议录制时改用要求更低的 OBS，或把游戏缩到720p窗口运行。同时明确表示，如果想在电脑上录制第一人称射击，这台机器可能并不合适；它更适合剪辑、修图和英雄联盟这类游戏。

- 原文依据："then this is the perfect PC. It runs all that really well"
