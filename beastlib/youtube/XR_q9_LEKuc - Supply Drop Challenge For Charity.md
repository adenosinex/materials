# 为慈善而设的补给箱挑战

## 视频简介
作者为自己设计了一项《使命召唤》挑战：随机开启补给箱，用抽到的武器打一场自由混战，若未能取胜就向慈善机构捐出十美元，并点名两位朋友接力。

## 内容摘要
视频开头作者放弃了一个原定项目，转而进行补给箱挑战，规则仿照 ALS 冰桶挑战：开一次补给箱，用抽到的武器打一场自由混战，输了就向慈善机构捐十美元，并把挑战传给另外两人。他点名两位朋友并给出一周完成时间，自己抽到的是短管霰弹枪。首局因进入时已接近结束而作废，随后一场对局中他多次弹匣打空并被击杀，最终仍赢下比赛，因此没有捐款。

## 关键事件
### E01｜放弃原项目改做新挑战
作者说明自己原本在做一个视频项目，因为过程不够有趣而放弃，改为拍摄当天的新内容。
- 原文依据："I decided to scrap the project because I wasn't having that much fun"

### E02｜公布补给箱挑战规则
作者介绍玩法：开启一次补给箱，用抽到的武器进入自由混战，若没赢下比赛就捐款。
- 原文依据："if I do not win that free for all match with the weapon I get"

### E03｜仿照冰桶挑战设置接力机制
作者称这一形式类似 ALS 冰桶挑战，需要把挑战转交给其他人，希望借此带动一种风气。
- 原文依据："you challenge two other people, you like pass it on to other people"

### E04｜点名两位朋友并给出一周期限
作者点名两位朋友参与，并说明他们没有义务提及自己，只需按同样规则完成。
- 原文依据："I'd like to challenge my friend Flip Arts in Immortality"

### E05｜抽到的武器是短管霰弹枪
作者开出补给箱后确认使用短管霰弹枪，并表示自己平时很少用这类枪械。
- 原文依据："Alright, so we're using the shorty"

### E06｜首局因时间不足作废
作者进入的房间对局已接近结束，他说明这种情况不计入挑战，将在下一局重新开始。
- 原文依据："I got put in a game that was almost over, so I didn't count that"

### E07｜对局中屡次子弹耗尽并被击杀
作者在使用短枪的过程中多次打空弹匣、被对手击杀，对局面一度不顺利。
- 原文依据："I ran out of bullets, so that works"

### E08｜赢下对局因此无需捐款
作者最终取得该场自由混战的胜利，因此按规则不必捐出十美元，并再次提到被点名的两位朋友。
- 原文依据："If I would have lost, I would have had to donate ten dollars, but I didn't"
