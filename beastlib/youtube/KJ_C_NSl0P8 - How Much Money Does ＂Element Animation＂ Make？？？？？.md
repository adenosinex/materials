# 「Element Animation」到底赚多少钱？？？？？

本期视频估算动画团队 Element Animation 在 YouTube 上的收入。讲述者先给出该频道的订阅数、总播放量与月播放量，再重点拆解他们新开的 Patreon 按视频打赏模式，说明打赏金额已接近广告分成，并据此推算团队每月的总体进账。

讲述者介绍，Element Animation 是一支动画团队而非单人频道，总播放量约一亿八千万次，订阅约一百五十万，每月播放约七百万次，广告收入每月约一万四千美元。团队因人数多、想再招几名动画师而开设 Patreon，支持者按每个视频承诺金额，合计每期视频可得一万一千美元以上。讲述者推算，若每五天上传一期，仅打赏每月就超过六万美元；加上广告收入，团队每月合计约两万五千美元。他还提到最受欢迎的系列是《Egg's Guide to Minecraft》，并称有一位支持者单个视频打赏一万美元。
