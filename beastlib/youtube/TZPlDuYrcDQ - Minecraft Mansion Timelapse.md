# 《我的世界》豪宅延时建造
## 视频简介
一段《我的世界》豪宅建造延时视频的结尾说明。作者介绍两位协助建造的伙伴，讲述素材重做经过，以及把一小时录像压缩成五分钟成片的做法。

## 内容摘要
视频主体是《我的世界》中一座豪宅的延时建造过程，但字幕正文只保留了结尾口播。作者先介绍画面右侧的 Penguin Man 和左侧的 DHD Tasty Pickle，称两人帮助他完成了建筑和视频。由于电脑上的存档文件出错，这座建筑实际上被建造了两次，两人虽然不太高兴，仍然配合重做。整段建造录制约一小时，被压缩成五分钟的延时成片，作者还提到可能把延时内容做成每周固定的栏目。

## 关键事件
### E01｜介绍两位协助建造的伙伴
作者在结尾出镜说明，画面右侧是 Penguin Man，左侧是 DHD Tasty Pickle，两人是这次建造的主要帮手。
- 原文依据："there's going to be two people: the guy on the right, Penguin Man"

### E02｜感谢两人让制作省事
作者向两位伙伴致谢，称他们让整个制作过程轻松顺利。
- 原文依据："shout out to those guys for making it easy and painless"

### E03｜存档损坏导致建筑重做一次
作者说明第一次的存档文件在电脑上出了问题，因此同一座建筑不得不重新建造。
- 原文依据："The save files got all screwed up on my computer, and so we actually had to do it again."

### E04｜一小时素材压缩成五分钟
作者称整段建造大约花了一小时，他把这一小时的录像剪辑成五分钟的延时视频。
- 原文依据："I took the hour file and condensed it to a five minute time lapse"

### E05｜提出做每周固定栏目
作者表示之后可能把延时建造做成每周一期的固定内容。
- 原文依据："We'll probably make this a weekly thing where we do time laps Tuesday every week"
